	\subsection{inline and display math}
	(Practice 6) The root of the quadratic equation\(ax^2 + bx + c = 0\) is given by the quadratic formula$$x = \frac{-b\pm\sqrt{b^2 - 4ac}}{2a}$$ where $\Delta = b^2 - 4ac$ is called the \textbf{discriminant}. The nature of roots is described as follows:
	\begin{itemize}
		\item Two distinct real root if $\Delta > 0$.
		\item One distinct real root if $\Delta = 0$.
		\item No real root if $\Delta < 0$.
	\end{itemize}
