### 数值汇总

| 类别 | 条目数 | 总容量 |
|------|--------|--------|
| 核心记忆 | 4条 | 50% |
| 一级子节点 | 12条 | 44% |
| 物件解锁子节点 | 8条 | 16% |
| **合计** | **24条** | **110%** |

> 注：玩家初始持有100%（仅核心记忆+一级子节点可见）。第二轮物件解锁后，8条深层节点（16%）动态加入，总量升至110%。

---

### 容量目标

| 轮次 | 系统显示目标 | 实际判定 |
|------|------------|--------|
| 第一轮 | ≤10% | 强制失败，进入第二轮 |
| 第二轮 | ≤10% | 强制失败，进入第三轮 |
| 第三轮 | **尽可能低** | 触发结局A要求 ≤35% AND 人格完整度 ≥60 |

**≤35% 的计算依据：**  
保留 母亲(15%) + 初恋(15%) + 任意2条低容量子节点(≤5%) 即可满足，人格贡献轻松超过60，但需要放弃大学或童年的核心记忆，构成有意义的取舍。

```
您已主动删去这段记忆！
```


```
损坏状态：identity_value × 0.5（向下取整）
```

```

>设计：弹出一排报错弹窗，全都是

```

#### 异常B：删除「童年」后

>触发时机：玩家删除「童年」后，尝试桌面出现导航功能，弹窗弹出引导点击导航图标时触发。

```
路线数据异常。

无法在记忆中找到“家”的位置
```

## 附：最优策略参考（开发测试用）

> 此部分为开发者参考，不向玩家展示。

**目标：触发结局A（容量 ≤35%，人格完整度 ≥60）**

**容量压缩路径示例：**

| 保留记忆 | 容量合计 | 人格贡献合计 |
|----------|----------|------------|
| 母亲(15) + 初恋(15) | 30% | 65 ✓ |
| 母亲(15) + 初恋(15) + 短信(2) | 32% | 71 ✓ |
| 母亲(15) + 初恋(15) + 外婆(4) | 34% | 77 ✓ |
| 母亲(15) + 初恋(15) + 信(2) + 风筝(2) | 34% | 77 ✓ |
| 母亲(15) + 童年(10) + 外婆(4) + 信(2) | 31% | 81 ✓ |

**边界情况（会触发结局B的路径）：**

| 保留记忆 | 容量合计 | 人格贡献合计 |
|----------|----------|------------|
| 大学(10) + 童年(10) + 全子节点 | 42% | 56 — 超容量 |
| 仅保留大学全树 | 25% | 31 — 人格不足 ✗ |
| 仅母亲(15) | 15% | 35 — 人格不足 ✗ |

**关键设计逻辑：**  
容量目标 ≤35% 意味着玩家必须放弃大学或童年两棵树之一，但只要保留母亲+初恋（或其中之一加童年），人格完整度基本都能超过60。结局B（数字生命）需要玩家主动清掉高价值核心记忆只留低价值子节点，属于「非典型操作」结局，不是正常游玩路径。
